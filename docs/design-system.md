# 전체 디자인 가이드 (v0.2)

> 폰트저울 · 무드보드 · 컬러 팔레트 세 서비스가 함께 쓰는 공통 디자인 규칙입니다.
> `[확정]` 사용자가 직접 정한 내용 / `[가정]` 제가 기본값으로 채운 내용 (수정하고 싶은 항목만 알려주세요)

---

## 0. 이 문서 사용법

서비스별 코드를 만들 때 "이 디자인 가이드를 따라서 만들어줘"라고 함께 전달합니다.
색·글자 크기·간격은 **직접 값을 쓰지 않고 4장의 토큰 이름**으로만 사용합니다. 값을 바꾸고 싶으면 토큰 정의만 고치면 세 서비스에 모두 반영됩니다.

## 1. 디자인 원칙

1. **콘텐츠가 주인공** `[확정: 중립 미니멀]`
   서비스의 주인공은 서체, 사진, 색입니다. 화면(UI)은 눈에 띄지 않는 흑백 모노톤으로 두고, 비교 대상이 돋보이게 합니다.
2. **포인트색은 아껴 쓴다** `[확정: 흑백 모노톤 + 포인트색 한 가지]`
   포인트색은 "지금 선택된 것, 지금 눌러야 하는 것"에만 씁니다. 한 화면에서 포인트색을 쓰는 **요소의 종류**가 3가지를 넘지 않게 합니다. 같은 종류의 요소는 여러 개여도 1가지로 셉니다. (예: 슬라이더가 2개여도 1가지, 저장된 별이 여러 개여도 1가지) `[확정: 종류 기준으로 세기]`
   포커스·마우스 올림·눌림 같은 일시적인 상태, 그리고 열려 있는 선택 창 안의 선택 표시는 개수에 넣지 않습니다. `[가정]`
3. **세 서비스는 한 제품처럼** `[확정: 탭으로 이동]`
   같은 요소(버튼, 입력창, 카드)는 어느 서비스에서든 같은 모양과 같은 위치에 둡니다.
4. **작업 중 빠르게 쓰는 도구** `[가정]`
   설명 없이 바로 쓸 수 있어야 합니다. 안내 문구는 짧게, 기능은 첫 화면에서 바로 보이게 합니다.

## 2. 화면 구조

```
┌──────────────────────────────────────────────────┐
│ 로고/이름                [폰트저울] 무드보드 컬러팔레트 │  ← 헤더 + 상단 가로 탭 [확정]
├──────────────────────────────────────────────────┤
│                                                  │
│   (서비스별 화면 영역)  최대 너비 1200px [가정]      │
│                                                  │
├──────────────────────────────────────────────────┤
│ 크레딧·출처 영역 (서비스에 따라 표시)                │
└──────────────────────────────────────────────────┘
```

| 항목 | 규칙 |
|---|---|
| 탭 메뉴 | 헤더 오른쪽 상단에 가로로 배치 `[확정]` |
| 본문 최대 너비 | 1200px, 좌우 가운데 정렬 `[가정]` |
| 화면 좌우 여백 | 데스크톱 32px, 모바일 16px `[가정]` |
| 우선 환경 | 데스크톱 브라우저 우선, 모바일은 보기 가능 수준 `[가정]` |
| 다크 모드 | 1차에서는 제외, 흰 배경만 제공 `[가정]` |

## 3. 서비스 구분 규칙

- **UI 영역과 콘텐츠 영역을 분리**합니다. 버튼, 탭, 라벨 같은 UI 글자는 항상 공통 UI 서체를 쓰고, 후보 폰트는 **폰트저울의 비교 카드 안 문장에만** 적용합니다. `[가정]`
  - 이유: UI 글꼴이 튀면 비교 대상 서체와 섞여 보여 비교가 흐려집니다.
- 무드보드의 사진, 컬러 팔레트의 색 칩은 **테두리와 그림자를 최소화**해서 콘텐츠 자체가 보이게 합니다. `[가정]`
- 서비스마다 다른 포인트색을 쓰지 않습니다. 포인트색은 세 서비스 모두 같은 한 가지입니다. `[확정: 포인트색 한 가지]`

**서비스별 포인트색 사용처 (현재 기획서 기준)** `[가정]`

| 서비스 | 포인트색을 쓰는 요소 종류 | 종류 수 |
|---|---|---|
| 폰트저울 | 선택된 탭, 슬라이더, 저장된 별 | 3 |
| 무드보드 | 선택된 탭, 주요 버튼(검색), 보드에서 선택된 사진 표시 | 3 |
| 컬러 팔레트 | 선택된 탭, 저장된 별 | 2 |

- 세 서비스 모두 3가지 이하라서 규칙을 지킨다. 서비스에 새 기능을 넣을 때는 이 표에 사용처를 추가하고 3가지를 넘는지 확인한다.

## 4. 디자인 토큰

### 4-1. 색

| 토큰 | 값 | 용도 | 대비 확인 |
|---|---|---|---|
| `--color-bg` | `#FFFFFF` | 기본 배경 | |
| `--color-surface` | `#F6F6F5` | 카드·입력창 배경 | |
| `--color-text` | `#111111` | 기본 글자 | 흰 배경 위 18.88:1 |
| `--color-text-sub` | `#5F6368` | 보조 글자 | 흰 배경 위 6.05:1 |
| `--color-text-muted` | `#6B7280` | 안내·플레이스홀더 | 흰 배경 위 4.83:1 |
| `--color-border` | `#D4D4D2` | 구분선, 카드 테두리 | |
| `--color-border-strong` | `#8A8A87` | 입력창·선택 영역 테두리 | 흰 배경 위 3.46:1 |
| `--color-accent` | `#2563EB` | 포인트색 `[가정]` | 흰 배경 위 5.17:1 |
| `--color-on-accent` | `#FFFFFF` | 포인트색 위 글자 | 5.17:1 |
| `--color-danger` | `#C62828` | 오류 메시지 `[가정]` | 사용 전 확인 |

- 포인트색 `#2563EB`(파랑)는 **임시 값**입니다. "한 가지"까지만 정하셨고 색 자체는 정하지 않으셔서 제가 골랐습니다. 마음에 드는 색이 있으면 `--color-accent` 값만 바꾸면 됩니다. `[가정]`
- 포인트색을 바꿀 때는 **흰 배경 위 글자로 쓸 수 있는 대비(4.5:1 이상)**인지 확인해야 합니다. 위 대비 수치는 계산한 값입니다.
- 색만으로 상태를 구분하지 않습니다. 선택된 탭이나 즐겨찾기는 색과 함께 밑줄, 채워진 별 같은 형태 변화도 줍니다. `[가정]`

### 4-2. 글자

| 토큰 | 값 | 용도 |
|---|---|---|
| `--font-ui` | `"Noto Sans KR", system-ui, sans-serif` | 모든 UI 글자 `[가정]` |
| `--text-title` | 24px / 굵기 700 / 줄간격 1.3 | 서비스 제목 |
| `--text-heading` | 18px / 굵기 600 / 줄간격 1.4 | 섹션 제목 |
| `--text-body` | 14px / 굵기 400 / 줄간격 1.6 | 기본 본문, 버튼 |
| `--text-caption` | 12px / 굵기 400 / 줄간격 1.5 | 크레딧, 안내문 |

- UI 서체는 개성이 약한 중립 서체로 잡았습니다. Noto Sans KR은 Google Fonts에서 불러올 수 있어서 폰트저울의 API와 같은 경로를 씁니다. 실제로 중립적으로 보이는지는 만들어 본 뒤 확인이 필요합니다. `[가정]`
- 글자 크기는 최소 12px 아래로 내려가지 않게 합니다. `[가정]`

### 4-3. 간격·모양

| 토큰 | 값 |
|---|---|
| `--space-1` ~ `--space-6` | 4 / 8 / 12 / 16 / 24 / 32px `[가정]` |
| `--radius-sm` | 6px (버튼, 입력창, 칩) `[가정]` |
| `--radius-md` | 12px (카드) `[가정]` |
| `--shadow-card` | 없음 (테두리 1px로 구분) `[가정]` |

### 4-4. CSS 변수로 쓸 때

```css
:root {
  --color-bg: #FFFFFF;
  --color-surface: #F6F6F5;
  --color-text: #111111;
  --color-text-sub: #5F6368;
  --color-text-muted: #6B7280;
  --color-border: #D4D4D2;
  --color-border-strong: #8A8A87;
  --color-accent: #2563EB;
  --color-on-accent: #FFFFFF;
  --color-danger: #C62828;

  --font-ui: "Noto Sans KR", system-ui, sans-serif;

  --space-1: 4px;  --space-2: 8px;  --space-3: 12px;
  --space-4: 16px; --space-5: 24px; --space-6: 32px;

  --radius-sm: 6px;
  --radius-md: 12px;
}
```

## 5. 공통 컴포넌트

### 5-1. 탭 내비게이션 `[확정: 상단 가로 탭]`

| 상태 | 모양 |
|---|---|
| 기본 | 보조 글자색(`--color-text-sub`), 밑줄 없음 |
| 마우스 올림 | 기본 글자색(`--color-text`) |
| 선택됨 | 기본 글자색 + 굵기 600 + 포인트색 밑줄 2px |
| 키보드 포커스 | 포인트색 외곽선 2px |

- 탭 순서: 폰트저울 → 무드보드 → 컬러 팔레트 `[가정]`
- 모바일: 화면 너비가 좁아지면 탭이 가로 스크롤되도록 하되, 선택된 탭이 항상 보이게 합니다. `[가정]`
- 탭을 전환해도 각 서비스에서 입력해 둔 값(문장, 검색어 등)이 사라지지 않게 합니다. `[가정]`

### 5-2. 버튼

| 종류 | 모양 | 쓰는 곳 |
|---|---|---|
| 주요 | 포인트색 배경 + 흰 글자 | 화면당 1개만 (예: 검색) |
| 보조 | 흰 배경 + 테두리 + 기본 글자 | 대부분의 일반 동작 |
| 텍스트 | 배경 없음 + 보조 글자 | 취소, 지우기 |
| 아이콘 | 36px 정사각 영역 | 즐겨찾기 별, 삭제 |

- 모든 버튼의 높이는 36px, 누를 수 있는 영역은 최소 36px로 합니다. `[가정]`
- 상태: 기본 / 마우스 올림(배경 한 단계 어둡게) / 눌림 / 비활성(투명도 40%) / 포커스(포인트색 외곽선 2px) `[가정]`

### 5-3. 입력창과 슬라이더
- 입력창: 높이 40px, `--color-surface` 배경, 테두리 `--color-border-strong`, 포커스 시 테두리가 포인트색으로 바뀜 `[가정]`
- 슬라이더: 막대는 `--color-border`, 선택된 구간과 손잡이는 포인트색, 현재 값을 오른쪽에 숫자로 함께 표시 `[가정]`
- 라벨은 입력창 위에 항상 보이게 둡니다. 플레이스홀더만으로 라벨을 대신하지 않습니다. `[가정]`

### 5-4. 카드
- 배경 `--color-bg`, 테두리 1px `--color-border`, 모서리 `--radius-md`, 안쪽 여백 `--space-4` `[가정]`
- 폰트저울의 비교 카드, 무드보드의 사진 카드, 컬러 팔레트의 색 칩 카드가 모두 이 틀을 씁니다.

### 5-5. 선택 창(검색 목록)
- 폰트저울의 폰트 검색, 무드보드의 사진 검색처럼 "검색 → 목록에서 고르기"가 나오는 곳에서 같은 형태를 씁니다. `[가정]`
- 위쪽 검색창, 아래쪽 스크롤 목록, 선택된 항목은 포인트색 체크 표시로 구분

### 5-6. 즐겨찾기 별
- 기본: 테두리만 있는 별(보조 글자색), 저장됨: 채워진 별(포인트색) `[가정]`
- 색뿐 아니라 채워짐 여부로도 구분합니다.

### 5-7. 크레딧 줄 `[가정]`
- 무드보드에서 사진을 보여줄 때 촬영자와 사진 제공처를 표시하는 한 줄 영역입니다. `--text-caption` 크기와 `--color-text-muted`색을 씁니다.
- 사진 제공처의 이용 조건은 서비스마다 다르므로, 실제 표시 방식은 무드보드 기획서에서 해당 API의 가이드라인을 확인해 정합니다. (이 문서에서는 모양만 정의)

## 6. 상태 화면 `[가정]`

| 상태 | 표시 방식 |
|---|---|
| 비어 있음 | 가운데 정렬된 한 줄 안내 + 다음 행동 버튼 하나 (예: "폰트를 검색해서 추가해 보세요") |
| 불러오는 중 | `--color-surface` 색의 자리 표시 박스. 글자로 "로딩 중"만 쓰지 않음 |
| 오류 | `--color-danger` 글자로 원인을 쉬운 말로 + "다시 시도" 버튼 |
| 한도 초과 | "잠시 후 다시 시도해 주세요"를 안내. 외부 서비스의 사용 한도 때문이라는 점을 알려줌 |

- 외부 서비스(Google Fonts, 사진 서비스, 색 서비스)의 호출이 실패해도 화면 전체가 멈추지 않고, 해당 영역에서만 오류가 보이게 합니다.

## 7. 접근성 기본선 `[가정]`

- 글자와 배경의 대비는 일반 글자 4.5:1 이상을 유지합니다.
- 모든 버튼과 탭은 키보드(Tab, Enter)로 조작할 수 있어야 합니다.
- 이미지(무드보드 사진)에는 대체 텍스트를 넣습니다. 사진 서비스가 설명 정보를 주는 경우 그 값을 사용하고, 없으면 검색어를 사용합니다.
- 색 칩에는 색 값(예: `#2563EB`)을 글자로도 함께 표시합니다.

## 8. 서비스별로 이 문서에서 추가로 정할 것

| 서비스 | 이 문서에 이미 있는 것 | 서비스별 기획서에서 정할 것 |
|---|---|---|
| 폰트저울 | 카드, 슬라이더, 선택 창, 즐겨찾기 별 | (폰트저울 기획서에서 정리 완료) |
| 무드보드 | 카드, 선택 창, 크레딧 줄 | 보드 레이아웃(자유 배치/격자), 저장 방식, 사진 제공처 이용 조건 반영 |
| 컬러 팔레트 | 카드, 입력창, 색 칩 표시 규칙 | 색 입력 방식, 조합 종류, 색 값 복사 기능 |

## 9. 열려 있는 질문

1. 포인트색을 `#2563EB`(파랑)로 둘지, 다른 색으로 바꿀지
2. 헤더 왼쪽에 들어갈 **세 서비스를 묶는 이름(통합 이름)** 이 필요한지 (지금은 "로고/이름" 자리만 있음)
3. 모바일에서 어느 정도까지 쓸 수 있게 할지 (보기만 가능 / 조작도 가능)

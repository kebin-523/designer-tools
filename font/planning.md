# 폰트저울 기획서 (v0.6)

> 서비스 이름: **폰트저울** `[확정]`
> 소개 문구: 한글 서체를 저울에 올리듯, 같은 문장으로 나란히 견줘보세요. `[가정: 추천 문구에 "한글"을 더해 다듬음]`

> `[확정]` 사용자가 직접 정한 내용 / `[가정]` 제가 기본값으로 채운 내용 (수정 필요하면 알려주세요)
> 공통 UI(색, 글자, 버튼, 카드, 탭 등)는 **전체 디자인 가이드(design-system.md)** 를 따릅니다. 이 문서에는 폰트저울만의 내용을 적습니다.

## 1. 한 줄 요약

한글 서체 후보 2~3개를 **같은 문장, 같은 조건**으로 나란히 놓고 비교해서, 작업 중인 디자이너가 빠르게 서체를 고를 수 있게 돕는 페이지. `[확정]`

## 2. 문제와 목표

**문제**
- 서체를 고를 때 폰트마다 탭을 바꾸거나, 디자인 툴에 일일이 텍스트를 복사해서 확인해야 해서 번거롭다. `[가정]`
- 같은 문장·굵기·크기로 놓고 봐야 공정한 비교가 되는데, 조건을 맞추기가 귀찮다. `[가정]`

**목표**
- 문장을 한 번 입력하면 모든 후보에 동시에 적용된다.
- 굵기·크기·자간도 한 번 조절하면 모든 후보에 동시에 적용된다.
- 마음에 드는 폰트는 저장해 두고 나중에 다시 꺼내 볼 수 있다.

## 3. 대상 사용자와 사용 상황

| 항목 | 내용 |
|---|---|
| 주 사용자 | 디자이너 `[확정]` |
| 사용 상황 | 작업 중 서체를 고를 때 `[확정]` |
| 사용 환경 | 데스크톱 브라우저 우선, 모바일은 보기만 가능하면 충분 `[가정]` |
| 사용 빈도 | 프로젝트 시작 시점이나 서체 교체를 고민할 때 간헐적으로 `[가정]` |

**대표 시나리오**
1. 앱 온보딩 화면 제목에 쓸 서체를 고민 중이다.
2. 실제 쓸 문구("오늘의 추천 코스를 확인해 보세요")를 입력한다.
3. 후보 3개를 골라 굵기를 Bold로, 크기를 32px로 맞춰 나란히 비교한다.
4. 가장 잘 맞는 서체를 저장하고, 팀원에게 이름을 알려준다.

## 4. 1차 버전(MVP) 범위

### 포함 `[확정]`

| 기능 | 설명 | 사용 예 |
|---|---|---|
| 비교 문장 직접 입력 | 입력창에 쓴 문장이 모든 후보 카드에 실시간 반영 | 실제 서비스 문구로 테스트 |
| 굵기·크기·자간 조절 | 슬라이더나 선택 UI로 조절하면 모든 후보에 동시 적용 | 본문(16px)과 제목(32px)에서 인상 차이 확인 |
| 폰트 즐겨찾기/저장 | 마음에 드는 폰트를 저장하고 목록에서 다시 불러오기 | 지난번에 찜해둔 폰트와 새 후보 비교 |
| 전체 목록 검색 | Google Fonts의 한글 지원 폰트 전체에서 이름으로 검색해 후보 선택 | 이름은 기억나는 폰트를 바로 찾아 비교 |

### 제외 (2차 이후 검토)

- 공유 링크, 이미지 저장 `[확정: 1차에서는 제외]`
- 로그인, 계정 연동 `[가정]`
- 폰트 파일 다운로드 `[가정]` (Google Fonts 공식 페이지로 안내하는 링크 정도만)
- 영문·숫자 전용 폰트 비교 `[가정]`

## 6. 기능 상세

### 6-1. 비교 문장 입력
- 기본 예시 문장을 미리 넣어둔다 (예: "다람쥐 헌 쳇바퀴에 타고파 1234"). `[가정]`
- 입력 즉시 모든 카드에 반영한다.
- 빠르게 바꿔볼 수 있는 샘플 문장 버튼(제목용, 본문용, 숫자 포함)을 둔다. `[가정]`

### 6-2. 굵기·크기·자간 조절

| 항목 | 방식 | 기본값 | 범위 | 
|---|---|---|---|
| 굵기 | 선택(드롭다운) | Regular(400) | 폰트가 지원하는 굵기만 노출 |
| 크기 | 슬라이더 | 32px | 12~96px `[가정]` |
| 자간 | 슬라이더 | 0 | -5%~+10% `[가정]` |

- 폰트마다 지원하는 굵기가 다르다. 선택한 굵기를 지원하지 않는 폰트는 가장 가까운 굵기로 보이게 하고, 카드에 작게 안내 표시를 한다. `[가정]`
- 조절값은 모든 후보에 공통 적용한다.

### 6-3. 폰트 선택
- Google Fonts Developer API에서 한글(korean) 지원 폰트 **전체 목록**을 불러와, 그 안에서 검색해서 고른다. `[확정]`
- 이름 검색을 기본으로 제공한다. 입력하는 대로 목록이 줄어드는 방식. `[가정]`
- 검색창을 누르기만 해도 보이는 기본 목록은 인기순으로 정렬한다. 처음 쓰는 사람이 검색어 없이도 고를 수 있게 하기 위함. `[가정]`
- 카테고리(고딕/명조/손글씨 등) 필터는 API가 주는 분류 정보를 활용하되, 분류가 충분치 않으면 1차에서는 이름 검색만 제공한다. `[가정]`
- 목록이 길 수 있어서, 후보 선택 칸마다 열리는 선택 창 안에서 스크롤하며 고르게 한다. `[가정]`
- 목록 안의 폰트 이름을 해당 폰트 모양으로 미리 보여줄지는 로딩 부담이 있어 1차에서는 하지 않고, 이름만 표시한다. `[가정]`

### 6-4. 즐겨찾기/저장
- 카드의 ☆ 버튼으로 저장·해제한다.
- 저장 목록에서 폰트를 누르면 빈 비교 칸에 바로 채워진다. `[가정]`
- 저장은 브라우저 안에 보관한다. 이 방식은 같은 브라우저·기기에서만 유지되고 다른 기기와는 연동되지 않는다. `[가정]`

### 6-5. 공통 디자인 적용 규칙 (design-system.md 기준)

**UI 영역과 콘텐츠 영역 분리** `[가정: 디자인 가이드 3장]`
- 후보 폰트는 **비교 카드 안의 문장에만** 적용한다.
- 탭, 라벨, 폰트 이름, 버튼, 안내문, 폰트 선택 목록의 이름은 모두 공통 UI 서체를 쓴다. UI 글꼴이 후보 폰트에 따라 바뀌면 비교 대상과 섞여 보이기 때문이다.

**공통 컴포넌트 적용**

| 요소 | 적용할 디자인 가이드 항목 |
|---|---|
| 비교 문장 입력창 | 5-3 입력창 (높이 40px, 라벨은 위에 항상 표시) |
| 굵기 선택 | 5-3 입력창 계열(선택 목록) |
| 크기·자간 슬라이더 | 5-3 슬라이더 (현재 값을 오른쪽에 숫자로 표시) |
| 후보 비교 카드 | 5-4 카드 (테두리 1px, 모서리 12px) |
| 폰트 선택 창 | 5-5 선택 창 (위쪽 검색창, 아래쪽 스크롤 목록, 선택된 항목은 포인트색 체크) |
| 즐겨찾기 별 | 5-6 즐겨찾기 별 (저장 전은 테두리 별, 저장 후는 채워진 별) |
| 샘플 문장 버튼 | 5-2 보조 버튼 |

**탭을 오가도 값 유지** `[가정: 디자인 가이드 5-1]`
- 다른 탭에 다녀와도 입력한 문장, 고른 후보 폰트, 굵기·크기·자간 값이 그대로 남아 있다.

**상태 화면** `[가정: 디자인 가이드 6장]`

| 상태 | 표시 방식 |
|---|---|
| 후보 칸이 비어 있음 | "폰트를 검색해서 추가해 보세요" 안내 + 폰트 추가 버튼 |
| 폰트 목록 불러오는 중 | 목록 자리에 자리 표시 박스 |
| 폰트 목록 호출 실패 | 선택 창 안에 쉬운 말의 오류 안내 + 다시 시도 버튼 (화면 전체는 멈추지 않음) |
| 선택한 폰트를 불러오지 못함 | 해당 카드 안에만 "폰트를 불러오지 못했어요" 안내 |
| 저장한 폰트가 없음 | 저장 목록 자리에 한 줄 안내 ("☆를 눌러 마음에 드는 폰트를 저장해 보세요") |

**접근성** `[가정: 디자인 가이드 7장]`
- 선택 창, 슬라이더, 버튼, 탭은 키보드로 조작할 수 있다. 슬라이더는 방향키로 값을 바꾼다.
- 굵기 미지원 안내는 색뿐 아니라 글자로도 표시하고, 저장 상태는 별의 채움 여부로도 구분한다.

**포인트색 사용처** `[가정]`
- 선택된 탭, 슬라이더, 저장된 별 세 종류만 포인트색을 쓴다. 디자인 가이드의 "요소 종류 3가지 이하" 규칙을 지킨다.

## 7. 기술 방향

| 항목 | 내용 |
|---|---|
| 제작 방식 | Claude로 HTML 파일로 제작, 서비스별로 파일 분리 `[확정]` / 공개 서비스로 게시 `[확정]` / 게시할 때의 파일 구성은 아직 미정 |
| 폰트 데이터 | Google Fonts Developer API로 목록 조회 `[확정]` |
| 폰트 적용 | 선택한 폰트를 Google Fonts CSS로 불러와 화면에 적용 `[가정]` |
| 저장소 | 브라우저 localStorage `[가정]` |
| UI 서체 | 디자인 가이드의 공통 UI 서체(Noto Sans KR), Google Fonts에서 불러옴 `[가정]` |

**미리 확인할 점**
- **API 키 노출**: 브라우저에서 실행되는 코드에 API 키를 넣으면 방문자가 볼 수 있다. 공개 서비스라면 Google Cloud에서 키의 사용 가능 도메인(HTTP referrer)을 제한하는 설정을 꼭 해두는 게 안전하다.
- **게시 환경의 외부 접속 허용**: 게시하는 곳에서 Google Fonts·API 주소로의 접속이 허용되는지는 코드를 만들기 전에 확인이 필요하다. (확인 전이라 단정하지 않음)
- **한글 폰트 로딩 속도**: 한글 폰트는 글자 수가 많아 처음 불러올 때 느릴 수 있다. 실제로 얼마나 걸리는지는 만들어 본 뒤 측정이 필요하다.

## 8. 성공 기준 (가볍게)

- 처음 방문한 디자이너가 설명 없이 1분 안에 3개 폰트를 비교해 볼 수 있다.
- 문장·굵기·크기·자간을 바꿨을 때 모든 카드가 지연 없이 함께 바뀐다.
- 저장한 폰트가 새로고침해도 남아 있다.
- 다른 탭에 다녀와도 입력한 문장과 고른 폰트가 그대로 남아 있다.
- 탭, 버튼 같은 UI 글자는 어떤 후보 폰트를 골라도 항상 같은 서체로 보인다.

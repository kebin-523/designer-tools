# app

탭 틀과 공통 스타일(디자인 토큰)을 둘 폴더입니다.
디자인 값은 `docs/design-system.md`를 따릅니다.

| 파일 | 역할 |
|---|---|
| `index.html` | **사이트의 기본 진입점.** 헤더와 탭을 보여주고, 탭마다 서비스 화면을 불러옵니다. 탭 목록과 경로는 이 파일의 `SERVICES`에서만 정합니다. |
| `shell.css` | 헤더, 탭, 서비스 제목 영역의 공통 스타일 |
| `tokens.css` | 디자인 토큰(CSS 변수) |

- 서비스의 `index.html`은 단독으로 여는 것을 지원하지 않습니다. 항상 `app/index.html`을 통해 엽니다. `[확정]`
- 서비스 `index.html`에는 헤더와 탭을 넣지 않습니다.
- 서비스 경로는 별도 HTML 기준 상대 경로입니다. 게시 구조가 정해지면 다시 확인합니다. `[가정]`

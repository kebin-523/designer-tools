# 무드보드 기획서 (v0.4)

> `[확정]` 사용자가 직접 정한 내용 / `[가정]` 제가 기본값으로 채운 내용 (수정하고 싶은 항목만 알려주세요)
> 공통 UI(색, 글자, 버튼, 카드, 탭 등)는 **전체 디자인 가이드(design-system.md)** 를 따릅니다. 이 문서에는 무드보드만의 내용을 적습니다.

---

## 1. 한 줄 요약

키워드로 무료 사진을 검색해 보드 위에 **자유롭게 배치**하고, 완성한 보드를 이미지로 저장해서 앱/웹 디자인 초기의 분위기 방향을 잡는 페이지. `[확정]`

## 2. 문제와 목표

**문제**
- 분위기 방향을 정할 때 사진을 여러 사이트에서 따로 찾아 캡처해서 한곳에 모으는 과정이 번거롭다. `[가정]`
- 모아 둔 사진을 한 화면에 나란히 놓고 봐야 "이 색감과 질감이 맞는지" 판단할 수 있다. `[가정]`

**목표**
- 검색부터 배치, 저장까지 한 화면에서 끝낸다.
- 사진이 주인공이 되도록 UI는 최소로 둔다. (디자인 가이드 원칙 1 `[확정]`)
- 팀원이나 동료에게 보여줄 수 있는 이미지 한 장이 나온다.

## 3. 대상 사용자와 사용 상황

| 항목 | 내용 |
|---|---|
| 주 사용자 | 디자이너 (폰트저울과 동일) `[가정]` |
| 사용 상황 | 앱/웹 디자인 초기에 분위기 방향을 잡을 때 `[확정]` |
| 사용 환경 | 데스크톱 브라우저 우선, 모바일은 보기 가능 수준 `[가정: 디자인 가이드와 동일]` |

**대표 시나리오**
1. 명상 앱의 온보딩 화면 분위기를 잡아야 한다.
2. "calm morning", "soft light", "minimal interior" 같은 키워드로 검색한다.
3. 마음에 드는 사진을 보드에 추가하고, 드래그로 위치와 크기를 조절해 분위기가 한눈에 보이게 배치한다.
4. 보드를 이미지로 저장해 팀 회의 자료에 붙인다.
5. 같은 사이트의 컬러 팔레트와 폰트저울 탭으로 넘어가 색과 서체를 정한다.

## 4. 1차 버전(MVP) 범위

### 포함 `[확정]`

| 기능 | 설명 | 사용 예 |
|---|---|---|
| 키워드로 사진 검색 | 검색어를 입력하면 사진 목록이 나온다 | "soft light"로 검색해 후보 훑어보기 |
| 사진 추가·삭제 | 목록에서 사진을 눌러 보드에 추가, 보드 위 사진은 삭제 가능 | 어울리지 않는 사진은 바로 빼기 |
| 자유 배치 | 보드 위 사진을 드래그로 이동, 크기 조절 | 중요한 사진을 크게, 보조 사진은 작게 |
| 보드를 이미지로 저장 | 보드 모습을 이미지 파일로 내려받는다 | 회의 자료에 붙이기 |
| 자동 저장 | 보드를 고칠 때마다 브라우저에 자동으로 저장되어, 새로고침이나 탭 전환 후에도 그대로 남는다 | 실수로 새로고침해도 작업이 안 사라짐 |

### 제외 (2차 이후 검토)

- 보드 여러 개 만들기와 이름 붙이기 `[확정: 1차에서는 제외]`
- 사진마다 짧은 메모 `[확정: 1차에서는 제외]`
- 공유 링크, 로그인 `[가정]`
- 사진에서 색 뽑아 팔레트로 보내기 `[가정]` (실현 가능한지 아직 확인하지 않음)
- 사진 업로드 `[가정]`

## 5. 화면 구성

```
┌───────────────────────────────────────────────────────────┐
│  로고/이름                  폰트저울  [무드보드]  컬러 팔레트  │
├───────────────────┬───────────────────────────────────────┤
│ [ 키워드 검색 ] [검색] │  보드                  [이미지로 저장] │
│                   │  ┌─────────────────────────────────┐  │
│ ┌────┐ ┌────┐     │  │      ┌──────┐                    │  │
│ │사진 │ │사진 │     │  │      │ 사진 │    ┌───┐          │  │
│ └────┘ └────┘     │  │      └──────┘    │사진│          │  │
│ ┌────┐ ┌────┐     │  │  ┌────┐          └───┘          │  │
│ │사진 │ │사진 │     │  │  │사진 │                        │  │
│ └────┘ └────┘     │  │  └────┘                         │  │
│ (스크롤)           │  └─────────────────────────────────┘  │
│ 사진 제공: Pexels   │  사진 출처: 촬영자 이름 목록           │
└───────────────────┴───────────────────────────────────────┘
```

- **왼쪽 검색 패널, 오른쪽 보드** 구조 `[가정]`
- 검색 패널은 디자인 가이드의 "선택 창(검색 목록)" 형태를 따릅니다.
- 모바일에서는 보드를 보는 것까지만 보장하고, 편집은 데스크톱 기준으로 합니다. `[가정]`
- **포인트색 사용처**: 선택된 탭, 주요 버튼(검색), 보드에서 선택된 사진 표시 세 종류만 쓴다. "이미지로 저장"과 "새 보드 시작"은 보조 버튼으로 둔다. 디자인 가이드의 "요소 종류 3가지 이하" 규칙을 지킨다. `[가정]`

## 6. 기능 상세

### 6-1. 키워드 검색
- 검색창에 단어를 입력하고 검색 버튼이나 Enter로 실행한다. `[가정]`
- 결과는 격자 형태로 보여주고, 아래로 스크롤하면 더 불러온다. `[가정]`
- 검색 결과가 없을 때는 "다른 키워드로 검색해 보세요" 안내를 보여준다. (디자인 가이드의 '비어 있음' 상태)
- **같은 검색어는 한 번 불러온 결과를 화면에서 재사용**해서 API 호출 횟수를 아낀다. `[가정]`
  - 이유: 무료 API는 사용 한도가 있어서, 같은 검색을 반복해도 호출이 늘지 않게 하려는 것
- 검색어는 영어가 더 잘 맞을 수 있는지 한글 검색이 되는지는 **아직 확인하지 않았습니다.** 만들기 전에 직접 검색해 보고 안내 문구를 정합니다.

### 6-2. 사진 추가·삭제
- 검색 결과의 사진을 누르면 보드 가운데 근처에 추가된다. `[가정]`
- 이미 추가한 사진은 목록에서 표시해서 중복 추가를 막는다. `[가정]`
- 보드 위 사진을 선택하면 삭제 버튼이 보이고, 키보드 Delete 키로도 삭제된다. `[가정]`
- 한 보드에 담을 수 있는 사진 수는 **20장**으로 제한한다. `[가정]` (화면이 느려지는 것을 막기 위한 임시 값, 실제 성능을 보고 조정)

### 6-3. 자유 배치 `[확정]`

| 동작 | 방법 |
|---|---|
| 이동 | 사진을 드래그 |
| 크기 조절 | 선택된 사진 모서리의 손잡이를 드래그. 가로세로 비율은 유지 `[가정]` |
| 앞으로 가져오기 | 사진을 누르면 맨 위로 올라옴 `[가정]` |
| 선택 표시 | 포인트색 테두리 2px와 모서리 손잡이 (색만으로 구분하지 않음) |

- 보드 영역 밖으로 사진이 완전히 나가지 않게 한다. `[가정]`
- 사진을 겹쳐 놓을 수 있다. `[가정]`
- 되돌리기(Ctrl+Z)는 1차에서 제외한다. `[가정]`

### 6-4. 보드를 이미지로 저장 `[확정]`
- 보드 오른쪽 위의 "이미지로 저장" 버튼으로 현재 보드를 이미지 파일로 내려받는다.
- 저장되는 이미지에는 **사진 출처(촬영자와 사진 제공처)를 하단에 함께 넣는 것**을 기본으로 한다. `[가정]`
  - 이유: 사진 제공처가 크레딧 표시를 요구하는데, 저장한 이미지가 다른 곳에서 쓰일 때도 출처가 남는 게 안전하기 때문. 저장 이미지에도 표시해야 하는지는 약관을 확인해야 한다.
- 보드가 비어 있으면 버튼을 비활성 상태로 둔다. `[가정]`
- 파일 형식과 이름은 PNG, `무드보드_날짜.png` 형태를 기본으로 한다. `[가정]`

### 6-5. 사진 출처(크레딧) 표시 `[가정]`
- 검색 패널 아래에 "사진 제공: Pexels" 링크를 항상 보여준다.
- 보드 아래에 **현재 보드에 있는 사진의 촬영자 이름 목록**(촬영자 페이지 링크 포함)을 모아서 보여준다.
- 보드 위 사진 위에 직접 이름을 올리면 화면이 지저분해지므로, 모아서 보여주는 방식으로 정했다.
- 이 방식이 사진 제공처의 크레딧 규정을 만족하는지는 **확인이 필요**하다. 만족하지 않으면 사진마다 표시하는 방식으로 바꾼다.

### 6-6. 자동 저장 `[확정]`
- 사진을 추가·삭제하거나, 이동·크기 조절을 마칠 때마다 보드 상태를 **브라우저에 자동 저장**한다. `[가정: 저장 시점]`
- 저장하는 것은 사진 이미지 자체가 아니라, **각 사진의 식별 정보, 보드 위 위치와 크기, 촬영자 이름과 링크**다. 사진은 다시 열 때 사진 제공처에서 불러온다. `[가정]`
- 페이지를 다시 열거나 다른 탭(폰트저울, 컬러 팔레트)에 다녀와도 보드가 그대로 복원된다.
- 같은 브라우저와 같은 기기에서만 유지된다. 다른 기기나 다른 브라우저에서는 보이지 않고, 브라우저의 사이트 데이터를 지우면 함께 사라진다. 화면에 이 점을 한 줄로 안내한다. `[가정]`
- **새 보드 시작** 버튼으로 보드를 비울 수 있다. 실수로 누르지 않게 "현재 보드가 삭제됩니다" 확인 창을 거친다. `[가정]`
- 저장이 실패하는 경우(저장 공간이 막혀 있는 브라우저 설정 등)에도 화면은 정상 동작하고, "자동 저장이 되지 않고 있어요"라는 안내만 보여준다. `[가정]`
- 저장된 사진이 나중에 불러와지지 않으면, 그 자리에 빈 박스와 "사진을 불러오지 못했어요" 안내를 보여주고 삭제할 수 있게 한다. `[가정]`

## 7. 기술 방향

| 항목 | 내용 |
|---|---|
| 사진 데이터 | Pexels API `[확정: 앞서 합의한 조합]` |
| 제작 방식 | HTML 파일로 제작, 서비스별로 파일 분리, 세 서비스를 탭으로 전환 `[확정]` / 게시할 때의 파일 구성은 아직 미정 |
| 보드 상태 | 브라우저에 자동 저장 `[확정]` (저장 방식은 브라우저 내 저장소를 쓰는 것으로 가정 `[가정]`) |

**Pexels API에서 확인된 내용**
- 사용하려면 **API 키**가 필요하고, 계정이 있으면 키를 바로 받을 수 있습니다. 기본 사용 한도는 시간당 200회, 월 20,000회이며, 조건을 지키면 한도 해제를 무료로 요청할 수 있습니다.
- Pexels와 촬영자의 크레딧을 서비스 안에 표시해야 하고, 월페이퍼 앱처럼 Pexels의 핵심 기능을 그대로 복제하는 용도는 허용되지 않습니다.
- 무드보드는 사진을 모아 새로운 가치를 만드는 서비스라 허용 범위에 들어갈 것으로 보이지만, 최종 판단은 약관에서 확인해야 합니다.

**미리 확인할 점**
1. **API 키 노출**: 브라우저에서 실행되는 코드에 키를 넣으면 방문자가 볼 수 있습니다. Pexels 키에 사용 가능 도메인을 제한하는 기능이 있는지는 확인하지 못했습니다. 없다면 키를 대신 들고 있는 중간 서버(프록시)가 필요합니다. (폰트저울의 Google Fonts 키와 함께 한 번에 결정)
2. **이미지 저장 기능의 실현 가능성**: 외부 서버의 사진이 들어 있는 화면을 이미지로 저장할 때, 브라우저 보안 규칙 때문에 막힐 수 있습니다. Pexels 사진 서버에서 가능한지는 직접 시험해 봐야 알 수 있고, 안 되면 대안(예: 사진을 내려받아 합치는 방식, 또는 저장 기능 변경)을 정해야 합니다.
3. **게시 환경의 외부 접속 허용**: 게시하는 곳에서 Pexels API 주소와 사진 주소로의 접속이 허용되는지 확인이 필요합니다.
4. **한도 초과 시 동작**: 한도에 도달하면 안내 문구를 보여주도록 합니다. (디자인 가이드의 '한도 초과' 상태 `[가정]`)

## 8. 성공 기준 (가볍게)

- 처음 방문한 디자이너가 설명 없이 3분 안에 사진 5장을 검색해 배치하고 이미지로 저장할 수 있다.
- 사진을 드래그하고 크기를 바꿀 때 끊김이 느껴지지 않는다. (20장 기준)
- 저장한 이미지에서 사진이 깨지지 않고, 출처가 확인된다.
- 새로고침하거나 다른 탭에 다녀와도 보드의 사진, 위치, 크기가 그대로 복원된다.

## 9. 열려 있는 질문

1. 검색어를 **한글로도** 입력할 수 있어야 하는지 (지원 여부는 확인 후 결정)
2. 저장 이미지의 **보드 크기**(정사각형, 16:9 등 고정) 또는 화면 크기에 맞출지
3. 이미지 저장이 기술적으로 막힐 경우 어떤 대안으로 갈지

> 해결됨: 보드는 브라우저에 자동 저장한다. 보드는 한 개만 쓴다. (4장, 6-6 반영)
